# Сайт ГК УР — Битрикс24, 1С и слаботочные системы

Многостраничный сайт для получения заявок: 3D-сцена в hero, скролл-история со схемой,
калькулятор цены, кейсы с фильтром и отдельными страницами, страницы услуг с пакетами,
«О компании», контакты и защищённая форма заявки с отправкой в Битрикс24.

## Страницы

| Адрес | Что там |
|---|---|
| `/` | 3D-hero, технологии, услуги, скролл-история «от кабеля до отчёта», кейсы, процесс, калькулятор, отзывы, FAQ, заявка |
| `/uslugi` | Все услуги с ценами и интеграции между системами |
| `/uslugi/bitrix24`, `/uslugi/1c`, `/uslugi/slabotochnye-sistemy` | Работы и цены, пакеты, этапы, галерея, кейсы, FAQ, заявка |
| `/kejsy`, `/kejsy/[id]` | Кейсы с фильтром и подробной историей проекта |
| `/o-kompanii` | История, команда, принципы, документы, отзывы |
| `/kontakty`, `/kalkulyator`, `/privacy` | Контакты, калькулятор, политика |

## Запуск

```bash
npm ci
cp .env.example .env.local   # заполните BITRIX24_WEBHOOK_URL, NEXT_PUBLIC_SITE_URL, по желанию TELEGRAM_*
npm run dev
```

## Проверки

```bash
npm run lint && npm run typecheck && npm test && npm run build
```

| История, отделы, принципы, документы | `src/content/company.ts` |
| Формула калькулятора | `src/lib/estimate.ts` (+ тесты в `tests/`) |

Сейчас контакты, реквизиты, цифры, кейсы, отзывы, история и документы — **демо-данные**. Замените их
на реальные до публикации: вымышленные отзывы и кейсы показывать как настоящие нельзя.

## Анимации

Плавный скролл — Lenis, скролл-сцены — GSAP ScrollTrigger и Motion, 3D — three.js.
Сфера в hero загружается отдельным чанком по первому действию человека и не запускается
на слабых устройствах, в режиме экономии трафика и при `prefers-reduced-motion`.
У всех бесконечных анимаций есть пауза.

## Заявки

Форма → Server Action `src/app/actions.ts`: валидация zod на сервере, honeypot, проверка
времени заполнения, лимит 5 валидных заявок за 10 минут с одного IP, цена калькулятора
пересчитывается на сервере.

Заявка с именем и телефоном создаётся лидом в Битрикс24 через входящий вебхук (права: CRM) —
данные остаются на серверах в РФ (152-ФЗ). В Telegram, если он настроен, приходит только
уведомление «Новая заявка №… в Битрикс24» без персональных данных. Без вебхука в продакшене
форма показывает ошибку и просит позвонить, в dev — печатает заявку в консоль.

Лимит заявок хранится в памяти процесса. На Vercel с несколькими инстансами замените его на
Upstash Ratelimit; для сильной защиты от ботов добавьте Cloudflare Turnstile.
Текст политики конфиденциальности — шаблон: согласуйте с юристом.

## Безопасность

Заголовки (CSP, HSTS, nosniff, X-Frame-Options, Referrer-Policy, Permissions-Policy) — в
`next.config.ts`. CSP без nonce, чтобы страницы оставались статичными; при подключении
Яндекс Метрики добавьте её домены в CSP.
